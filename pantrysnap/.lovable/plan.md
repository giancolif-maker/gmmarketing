# Make Pantry Snap installable

## Build
- Add complete home-screen manifest metadata for Pantry Snap.
- Add branded phone, tablet, and browser icons.
- Add iOS home-screen and status bar metadata.

## Validation
- Confirm every manifest asset loads and has the declared dimensions.
- Confirm the browser recognizes the app manifest.

## Technical details
- This is manifest-only installability. It intentionally does not add offline caching or a service worker.
